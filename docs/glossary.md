# Glossary

- **Agent run:** A single bounded attempt by an agent to execute a work node.
- **Approval boundary:** A point beyond which execution requires authorization from a designated actor.
- **Budget:** An explicit resource limit, such as cost, tokens, runtime, tool calls, or concurrency.
- **Constraint:** A requirement that must remain true while pursuing an objective.
- **Evidence:** An inspectable artifact or observation supporting or contradicting a claim about an outcome.
- **Execution state:** The operational status of a run or node; it is distinct from whether the objective is achieved.
- **Invariant:** A condition that must not be violated, regardless of the execution strategy.
- **Objective:** A desired outcome described by success criteria, constraints, and relevant context.
- **Objective contract:** The structured definition of an objective and its authority, budgets, and acceptance conditions.
- **OCEAN:** Objective-Centered Execution and Adaptive Navigation; a proposed agent-oriented operating methodology.
- **Work graph:** A dynamic representation of tasks, investigations, experiments, decisions, verifications, and their dependencies.
- **Verified outcome:** A result for which the required acceptance criteria have been checked against adequate evidence.
